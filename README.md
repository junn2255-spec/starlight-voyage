# 별빛 항해

3050년 지구에서 출발하는 모바일 우주여행 게임.

[게임 플레이](https://junn2255-spec.github.io/starlight-voyage/)

전체화면으로 시작을 누르면 화면 전환이 완료된 후 음악과 게임이 시작됩니다. 지원하지 않는 브라우저에는 일반 화면 시작 선택지가 표시됩니다.

지구 출발 → 조종석 비행 7초 → 사막의 별 착륙 → 터치 이동. 채굴·건설은 아직 구현되지 않았습니다.

음원 출처는 assets/stage01/audio/manifest.json 및 각 소리에셋의 출처 파일, 폰트 라이선스는 fonts/ 폴더에서 확인할 수 있습니다.
